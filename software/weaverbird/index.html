Software · Platform

Weaverbird

Weaverbird is our plugin platform. It is the reason a small engineering team ships complete software products for many markets: the hard, common parts are built once, and each product is a set of plugins on top.

Build a product on WeaverbirdAll software

How it works

One shared base

Accounts, organizations, roles and permissions, notifications and billing are built once, in the platform core. Every product gets them for free.

Products are plugins

A product is a set of plugins on the core — its data models, screens and APIs. New products reuse everything the platform already does.

Web, Android and devices

The same backend serves the web apps, the Android apps and connected devices — keypads, kiosks, meters and bridges.

Multi-tenant SaaS

Each product runs as SaaS with its own tenants — an organization signs up, installs the plugins it needs, and runs.

Where to use it

A SaaS product of your own

Bring a product idea; the accounts, permissions, billing and data layers are already built — you build the plugins that make it yours.

Running a business

Use the shipped products — receipts, records, identity, farm and school management — as an organization, without building anything.

Connected hardware

Products that pair software with devices — keypads, kiosks, meters and dispensers — talk to the same platform.
